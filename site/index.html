How it works

  1. Every night the catalog reads the open pull requests to hacs/default and searches GitHub for every hacs.json. Whatever HACS already lists, or has removed, is left out, and so are archived repositories and forks.
  2. Each repository is held up against the checks HACS runs before it lists one. For those in the queue, the result of HACS's own action on the pull request is shown too. An integration whose domain is already taken by one in HACS or in Home Assistant is marked, since only one of them can be installed.
  3. The Python of each integration is read as code, not as text, for things worth a second look, such as running text as code or starting programs. A flag is a reason to read, not a verdict.
  4. Open in HACS takes you to your own Home Assistant through My Home Assistant. HACS asks whether to add the repository, and from then on installs and updates it like any other.
